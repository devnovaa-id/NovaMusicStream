# ✦ NovaMusicStream

> A modern Telegram voice-chat music player built with **Pyrogram**, **Telethon**, and **Py-TgCalls**.

NovaMusicStream is designed for Telegram groups that need a fast, reliable, and easy-to-operate music bot. It supports audio and video playback in voice chats, YouTube search and downloads, channel streaming, assistant-account management, inline controls, and role-based administration.

## ✨ Features

- 🎵 Play audio in Telegram voice chats.
- 🎬 Play video streams in Telegram video chats.
- 📡 Stream to broadcast channels with `/cplay` and `/cvplay`.
- 🔎 Search YouTube and inspect track information.
- ⏯️ Pause, resume, skip, and stop playback.
- 🎧 Download requested songs with `/song`.
- 🖼️ Automatic thumbnails and playback status messages.
- 🤖 Pyrogram bot client for commands and user interaction.
- 👤 Telethon assistant client for voice-chat operations.
- ⚡ Py-TgCalls integration for Telegram voice/video chats.
- 🛡️ Owner and sudo-user access control.
- 🧩 Modular command loading from `NovaMusic/Modules`.
- 🗂️ Local cache and download directory management.
- 🐳 Docker and Heroku-style deployment files included.

## 🧱 Architecture

```text
NovaMusicStream/
├── NovaMusic/
│   ├── Helpers/       # Downloaders, queues, formatting, thumbnails, utilities
│   ├── Modules/       # Telegram command modules, loaded automatically
│   ├── __init__.py    # Bot, assistant, and Py-TgCalls clients
│   └── __main__.py    # Startup sequence
├── config.py          # Environment configuration
├── .env.example       # Configuration template
├── requirements.txt   # Python dependencies
├── Dockerfile         # Container build definition
├── Procfile           # Process declaration
└── gen_telethon.py    # Assistant session generator
```

At startup, NovaMusic imports every Python module in `NovaMusic/Modules`. A new module can therefore be added without manually editing a central registry, provided it follows the project’s existing handler pattern.

## ✅ Requirements

- Python **3.9 or newer**
- FFmpeg
- Node.js/Deno when required by the media extraction stack
- A Telegram bot token from [@BotFather](https://t.me/BotFather)
- Telegram API ID and API hash from [my.telegram.org](https://my.telegram.org)
- A Telegram assistant session string
- A bot that is an administrator in the target group/channel
- The assistant account added to the voice chat and granted the required permissions

> The assistant account is important: Telegram bots cannot independently perform every voice-chat action, so NovaMusic uses a user session through Telethon together with the bot client.

## 🚀 Installation

### 1. Clone the project

```bash
git clone https://github.com/devnovaa-id/NovaMusicStream.git
cd NovaMusicStream
```

### 2. Create a virtual environment

```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Install system packages

Ubuntu/Debian:

```bash
sudo apt update
sudo apt install -y ffmpeg
```

### 4. Configure environment variables

```bash
cp .env.example .env
nano .env
```

Never commit `.env`, `cookies.txt`, session strings, or bot tokens to a public repository.

### 5. Generate the assistant session

Use the included generator:

```bash
python gen_telethon.py
```

Copy the generated string into `SESSION` in `.env`. The assistant account should be the account you want NovaMusic to use in voice chats.

### 6. Start NovaMusic

```bash
python -m NovaMusic
```

The application creates `downloads/`, `cache/`, and `novalogs.txt` when required.

## ⚙️ Environment variables

| Variable | Required | Description |
|---|:---:|---|
| `API_ID` | Yes | Telegram API ID from `my.telegram.org`. |
| `API_HASH` | Yes | Telegram API hash from `my.telegram.org`. |
| `BOT_TOKEN` | Yes | Token generated by `@BotFather`. |
| `SESSION` | Yes | Telethon assistant string session. |
| `OWNER_ID` | Yes | Numeric Telegram ID of the owner. |
| `SUDO_USERS` | Yes | Space-separated numeric IDs allowed to use sudo commands. |
| `DURATION_LIMIT` | No | Maximum media duration in seconds; default is `300`. |
| `PING_IMG` | No | Image used by the ping/status module. |
| `START_IMG` | No | Image used by the start message. |
| `SUPPORT_CHAT` | No | Public support group URL. |
| `SUPPORT_CHANNEL` | No | Public support channel URL. |

Example:

```dotenv
API_ID=123456
API_HASH=your_api_hash
BOT_TOKEN=123456:your_bot_token
SESSION=your_assistant_session_string
OWNER_ID=123456789
SUDO_USERS=123456789 987654321
DURATION_LIMIT=300
SUPPORT_CHAT=https://t.me/your_support_group
SUPPORT_CHANNEL=https://t.me/your_channel
```

## 🎛️ User commands

Run these commands in a group where the bot is present and the assistant can access the voice chat.

| Command | Description |
|---|---|
| `/play <query>` | Play an audio track or add it to the queue. |
| `/vplay <query>` | Play a video in the video chat. |
| `/cplay <query>` | Play audio in a broadcast channel. |
| `/cvplay <query>` | Play video in a broadcast channel. |
| `/pause` | Pause the current stream. |
| `/resume` | Resume the paused stream. |
| `/skip` | Skip the current track and play the next queued item. |
| `/end` | Stop playback and clear the queue. |
| `/song <query>` | Download and send an audio file. |
| `/search <query>` | Search YouTube and display results. |
| `/ping` | Show bot ping and system information. |
| `/sudolist` | Display the configured sudo users. |

The exact command menu is also available from Telegram’s bot command menu and the Help & Commands button in `/start`.

## 🛡️ Sudo and owner commands

### Sudo commands

- `/activevc` — list active voice chats.
- `/eval` or `/sh` — execute administrative code.
- `/speedtest` — run a server speed test.
- `/sysstats` — show server resource statistics.
- `/setname` — update the assistant account name.
- `/setbio` — update the assistant account bio.
- `/setpfp` — update the assistant account profile photo.
- `/delpfp` — remove the assistant account profile photo.

### Owner commands

- `/config` or `/variables` — inspect configuration values.
- `/broadcast` — broadcast a message to served chats.
- `/rmdownloads` — clear downloaded/cache files.
- `/leaveall` — make the assistant leave chats.
- `/addsudo` — add a sudo user.
- `/rmsudo` — remove a sudo user.

Use owner-level commands carefully. They can expose secrets or affect every chat served by the bot.

## 🏃 Running with PM2

PM2 is useful for long-running servers and automatic restarts:

```bash
npm install -g pm2
pm2 start "python3 -m NovaMusic" --name nova
pm2 save
pm2 startup
```

Useful commands:

```bash
pm2 status
pm2 logs nova
pm2 restart nova
pm2 stop nova
```

## 🐳 Docker

Build the image:

```bash
docker build -t novamusicstream .
```

The included `Dockerfile` contains the project’s deployment setup. Before running it in production, verify that its final command starts the application with:

```dockerfile
CMD ["python3", "-m", "NovaMusic"]
```

Then run the container with persistent media directories:

```bash
docker run -d \
  --name nova \
  --restart unless-stopped \
  --env-file .env \
  -v "$PWD/downloads:/app/downloads" \
  -v "$PWD/cache:/app/cache" \
  novamusicstream
```

For production, persist the download/cache directories and provide secrets through your deployment platform rather than baking them into the image.

## 🔐 Telegram setup checklist

1. Create a bot with `@BotFather`.
2. Enable inline mode if inline features are required.
3. Obtain `API_ID` and `API_HASH` from `my.telegram.org`.
4. Generate the assistant `SESSION` string.
5. Add the bot to the target group or channel.
6. Promote the bot with permission to manage messages as needed.
7. Add the assistant account to the voice chat.
8. Start the bot and test `/ping`.
9. Test playback with `/play <song name>`.

## 🧪 Troubleshooting

### Bot starts but playback fails

- Verify `API_ID`, `API_HASH`, `BOT_TOKEN`, and `SESSION`.
- Confirm FFmpeg is installed: `ffmpeg -version`.
- Make sure the assistant account is online and joined to the voice chat.
- Confirm the bot and assistant have the required group permissions.

### `SESSION` or Telethon connection errors

- Generate a new session using `gen_telethon.py`.
- Check that the phone number/account used for the session is correct.
- Do not reuse a corrupted or revoked session string.

### YouTube extraction errors

- Upgrade dependencies from `requirements.txt`.
- Check that the requested media is publicly accessible.
- Remove stale files from `cache/` and `downloads/` if a partial download is stuck.

### Bot crashes after an update

```bash
git pull
source venv/bin/activate
pip install -r requirements.txt
python -m compileall -q NovaMusic
pm2 restart nova
```

Check logs with:

```bash
pm2 logs nova --lines 100
```

## 🧩 Development

Keep new functionality modular:

1. Add a module under `NovaMusic/Modules/`.
2. Import `app` and the required Pyrogram filters from `NovaMusic`.
3. Implement handlers using the existing project style.
4. Keep secrets out of source code.
5. Run syntax checks before committing:

```bash
python -m compileall -q NovaMusic
git diff --check
```

For media-related changes, test both successful playback and failure handling. For queue changes, test multiple tracks, `/skip`, `/pause`, `/resume`, and `/end`.
